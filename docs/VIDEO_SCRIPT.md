# 2-minute demo video script

Record at 1080p with a phone-width browser window (375 px) for the app shots. Keep the cursor slow. Captions on.
Bracketed lines in **CAPS** are numbers you must fill from your own checks before recording; don't record placeholders.

| Time | Screen | Voice-over |
|---|---|---|

## Recording checklist
- Pre-load London and Chennai once before recording so the saved copy shows instantly.
- If live data doesn't arrive during the take, keep the saved copy: the badge is honest either way.
- Show the GitHub repo for 1 second at the end (judges score code quality).
